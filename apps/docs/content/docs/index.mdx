## Local by default

Specifications, Test runs, caches, and artifacts stay on your machine or CI runner by default. Pickle Spec does not require a hosted control plane.

The web adapter uses Stagehand for browser automation, and the mobile adapter uses Agent Device for Android Emulator and iOS Simulator automation. The CLI installs Studio as part of the compatible package set. Hosted synchronization and physical-device provisioning are outside the current release.
