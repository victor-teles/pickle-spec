Pickle Spec turns each Scenario into a real browser or device session. You write the behavior. Pickle owns execution, retries, evidence, results, and deterministic Replay.

## Local by default

Specifications, Test runs, caches, and artifacts stay on your machine or CI runner by default. Pickle Spec does not require a hosted control plane.
