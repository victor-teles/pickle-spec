The Pickle CLI already includes native support. It runs Android and iOS Scenarios through `@pickle-spec/mobile` and Agent Device.

<Callout type="warn" title="Emulators and Simulators only">
  Physical-device provisioning is outside the current release.
</Callout>

## Native execution model

Native steps use a closed vocabulary. Pickle compiles the complete Scenario into an Agent Device `.ad` script. The mobile adapter sends that script to an isolated Node.js worker through a versioned protocol.

| Gherkin step                       | Native operation                         |
| ---------------------------------- | ---------------------------------------- |
| `Given Welcome`                    | Wait for visible text `Welcome`.         |
| `When Continue`                    | Find `Continue` and click it.            |
| `Then Home`                        | Assert that text `Home` is visible.      |
| `Then visible: id="home"`          | Assert that the selector is visible.     |
| `Then hidden: id="spinner"`        | Assert that the selector is hidden.      |
| `Then text: id="greeting" = Hello` | Assert the selector text equals `Hello`. |

Explicit outcomes support `text`, `visible`, `hidden`, `exists`, `editable`, `selected`, and `focused`.

## Check the environment

`pickle check` validates the project files. `pickle doctor` checks Node, target discovery, and the configured device capabilities.

```npm
npx pickle check
npx pickle doctor
```

## Discover and configure an application

List application IDs from connected Android Emulators or iOS Simulators:

```npm
npx pickle apps --platform android
npx pickle apps --platform ios --all
```

Configure a mobile application by ID. Pickle Spec uses an Android Emulator when
`executionTarget` is omitted. Add `binaryPath` only when each run should
reinstall the application before launch.

```jsonc
{
  "schemaVersion": 1,
  "executionTargetProfiles": {
    "android": {
      "adapter": "mobile",
      "mobile": {
        "application": { "id": "com.example.checkout" },
      },
    },
  },
}
```

For iOS, select `ios-simulator` explicitly as shown in the [iOS guide](/docs/native/ios).
