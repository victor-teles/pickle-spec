## Prerequisites

Install **Node.js 24 or newer** and make sure `node` is available on your PATH. You can install Pickle with npm, pnpm, Yarn, or Bun. The CLI, Studio, and native worker run on Node.js; Bun is not required.

Pickle uses Node's built-in SQLite for the local execution cache and test-run index. Published packages contain compiled JavaScript and TypeScript declarations.

Web execution also needs a browser and model credentials for Adaptive execution. Native execution also needs an Android Emulator or iOS Simulator. The target-specific quick starts cover those requirements.

## Install the CLI

Run this command from your application repository. Choose your package manager; the documentation remembers your selection across command examples.

```npm
npm install --save-dev @pickle-spec/cli
```

## Initialize your project

Use your package manager to run the locally installed `pickle` executable:

```npm
npx pickle init
```

`pickle init` creates a configuration shell; it does not create a demonstration
or claim a successful application test. Follow the
[web quick start](/docs/web/quick-start) to configure a real
target and add a meaningful assertion before opening Studio. Studio then shows
the exact setup checks blocking the first run and starts one Scenario at a time.

The CLI package installs Studio as part of the compatible package set. Pickle
Spec does not require a cloud service. This release excludes hosted
synchronization and physical-device provisioning.

## Open Studio

After configuring your target and adding a Specification, open the local UI:

```npm
npx pickle studio
```

## Next steps

Start with the [web quick start](/docs/web/quick-start) or choose an [Android Emulator or iOS Simulator](/docs/native). Once your project is configured, [open Studio](/docs/guides/studio) or [run from the CLI](/docs/guides/running-tests).
